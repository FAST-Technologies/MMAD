## 📋 Описание проекта

Данный проект представляет собой полное решение задачи многоклассовой классификации на датасете **[Car Evaluation](https://archive.ics.uci.edu/dataset/19/car+evaluation)** из репозитория UCI. Датасет содержит 1728 объектов и 6 категориальных признаков, описывающих характеристики автомобилей, и 4 класса оценки приемлемости (`unacc`, `acc`, `good`, `vgood`).

**Ключевая особенность работы** — не просто построение моделей, а их **глубокий сравнительный анализ** с применением современных инструментов интерпретации (SHAP) и автоматизированного подбора гиперпараметров (Optuna).

## 🎯 Условия задачи

### Задача 1: Разведочный анализ данных (EDA)
Загрузить таблицу **Car Evaluation** из репозитория UCI. Поместить данные в объект `DataFrame` библиотеки `pandas`. Визуализировать распределения классов на всех парах переменных.

### Задача 2: Сравнение алгоритмов классификации
Выбрать две переменные. Построить и визуализировать (показать разделяющую кривую) решения методами:
- Линейный дискриминант (LDA)
- Квадратичный дискриминант (QDA)
- Логистическая регрессия
- SVM (линейное ядро)
- SVM (квадратичное ядро)

Оценить качество классификации этими методами при помощи кросс-валидации на выбранных признаках и во всем признаковом пространстве.

### Задача 3: Визуализация LDA
Построить **линейный дискриминант** на всех переменных. Визуализировать ответы алгоритма (цветом) на обучающей выборке и классы объектов (формой маркеров) во всех двумерных подпространствах.

## 🏆 Ключевые результаты

### Сравнение моделей (после оптимизации Optuna)

| Модель | CV Accuracy | AUC-ROC (macro) | AP (macro) | AP для min. классов |
|--------|-------------|-----------------|------------|---------------------|
| **SVM (poly, degree=3)** 🥇 | **0.9936** | **0.9998** | **0.9985** | **0.99+** |
| QDA (оптимизированный) 🥈 | 0.9080 | 0.9821 | 0.9412 | ~0.85 |
| SVM (linear) | 0.7876 | 0.9512 | 0.8234 | ~0.45 |
| Logistic Regression | 0.8206 | 0.9634 | 0.8567 | ~0.55 |
| LDA (shrinkage=auto) | 0.8154 | 0.9589 | 0.8423 | ~0.50 |

### Главные выводы

1. **🎯 Лучшая модель** — SVM с полиномиальным ядром 3-й степени достиг точности **99%** благодаря учету нелинейных взаимодействий признаков.
2. **📉 Линейные модели** (LDA, Logistic) достигли "потолка" ~82% из-за нелинейной природы задачи и дисбаланса классов.
3. **🔍 Ключевые признаки** (по SHAP): `safety` и `persons` — решающие факторы для классов `good` и `vgood`.
4. **⚖️ Дисбаланс классов** (70% vs 4% vs 4%) критически важен: только PR-кривые и Average Precision показали реальную способность моделей находить редкие классы.

## 📈 Визуализации

В работе построены следующие типы графиков:

- **PairGrid** — распределения классов на всех парах переменных
- **Decision Boundaries** — разделяющие поверхности 5 моделей в 2D
- **Confusion Matrices** — матрицы ошибок для каждой модели
- **Learning Curves** — анализ переобучения/недообучения
- **Calibration Curves** — калибровка вероятностей
- **ROC & Precision-Recall Curves** — сравнение моделей на несбалансированных данных
- **SHAP Summary Plots** — интерпретация вкладов признаков (LinearExplainer + KernelExplainer)
- **LDA 2D Projections** — 15 подпространств с визуализацией предсказаний vs истинных классов

## 🧠 Методологические особенности

### Обработка категориальных признаков
Применено **порядковое кодирование (Ordinal Encoding)** с сохранением семантики:
```python
'safety': {'low': 0, 'med': 1, 'high': 2}
'persons': {'2': 0, '4': 1, 'more': 2}
```

### Оптимизация гиперпараметров
Использован фреймворк **Optuna** (50 trials на модель) для поиска оптимальных параметров:
- `C`, `degree`, `gamma` для SVM
- `reg_param`, `tol` для QDA
- `solver`, `shrinkage` для LDA

### Интерпретация нелинейных моделей
Для интерпретации лучшей модели (SVM Poly) использован `shap.KernelExplainer` с:
- Фоновым набором через `shap.kmeans(X, 50)`
- Подвыборкой 200 объектов для быстрой отрисовки
- Функцией-обёрткой `predict_proba_class1` для корректной работы с многоклассовостью
